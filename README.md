# Humans Apocalypse
Arena shooter roguelite prototype. **A zombie survives an invasion of humans.**

## Status
- Browser-playable vertical-prototype experiment, **not production-ready**
- Desktop keyboard WASD / mouse aim / automatic shooting / Space dash
- Five waves, human enemy variants, between-wave mutation picks, health pickups
- This build uses **placeholder vector art**, not the recovered Construct 2 sprites or cutscenes.
- Source history of the previous WorkflowProduct repository is preserved in branch `backup/workflowproduct-before-humans-apocalypse`.

## Deploy
Repository Settings → Pages → Build and deployment → Source: GitHub Actions.
The deploy workflow tracks the current default branch: `claude/product-packshot-lifestyle-workflow-4ap9d2`.
If publishing isn't enabled, the play link will not work until this one-time setup.

## Long-term technical plan
Extract modules, add automated tests, clean licensing provenance, define original art direction, build a Godot prototype before scaling, and maintain a separate release branch.
